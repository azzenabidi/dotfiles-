# Dispatch

Dark theme inspired by the [Dispatch](https://store.steampowered.com/app/2592160/Dispatch/) video game by AdHoc Studio.

Deep blacks, electric blues, and warm ambers — capturing the gritty urban superhero atmosphere of the game.

## Colors

| Role | Color |
|------|-------|
| Background | `#0a0e17` |
| Foreground | `#e0e4ec` |
| Accent (Blue) | `#1e90ff` |
| Secondary (Amber) | `#ff8c00` |
| Red | `#dc143c` |
| Green | `#20b2aa` |
| Purple | `#7b68ee` |
| Cyan | `#00ced1` |

## Applying

```bash
omarchy-theme dispatch
```
